# Weather App

A responsive weather application built with HTML, CSS, and JavaScript. It uses the Open-Meteo APIs to search for a city and display its current weather and 5-day forecast.

## Features

- Search weather by city name
- Display current temperature and weather condition
- Display wind speed, humidity, and pressure
- Display a 5-day weather forecast
- Handle empty or invalid city searches
- Show a loading message while fetching data
- Responsive design for different screen sizes

## Technologies Used

- HTML
- CSS
- JavaScript
- Fetch API
- Open-Meteo API

## APIs Used

- Open-Meteo Geocoding API
- Open-Meteo Forecast API

## How It Works

1. Enter a city name in the search box.
2. The Geocoding API finds the city's latitude and longitude.
3. The coordinates are used to fetch weather data.
4. The application displays the current weather and 5-day forecast.
